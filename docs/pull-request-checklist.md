# Pull Request Checklist

Before merging a Pull Request, verify the following:

- [ ] The purpose of the change is clearly explained.
- [ ] Changes are limited to the intended task.
- [ ] Documentation has been reviewed.
- [ ] No passwords, tokens, or secrets are included.
- [ ] The changed files have been checked.
- [ ] The branch is ready for review.

## Review Workflow

1. Push the feature branch to GitHub.
2. Open a Pull Request targeting the dev branch.
3. Review the changes.
4. Merge after confirming the changes are correct.
