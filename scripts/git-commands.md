# Useful Git Commands Reference

| Command | Purpose |
|---|---|
| `git init -b main` | Initialize a repository with main |
| `git status` | Check working-tree status |
| `git add .` | Stage changes |
| `git commit -m "message"` | Create a commit |
| `git branch` | List local branches |
| `git switch -c dev` | Create and switch to a branch |
| `git switch main` | Switch to main |
| `git merge branch-name` | Merge another branch |
| `git log --oneline --graph --all` | View commit history |
| `git stash` | Temporarily save uncommitted changes |
| `git stash pop` | Reapply stashed changes |
| `git fetch origin` | Retrieve remote updates |
| `git push -u origin branch-name` | Publish a branch |
| `git tag` | List tags |
| `git diff` | Inspect changes |
| `git remote -v` | Show remote repository URLs |
